## 정수 N개의 합 2

20XP

평균 13분

77% 정답률

총 제출 1,458회

N개의 원소로 이루어진 수열이 주어졌을 때, 이 중 연속하는 K개의 원소들의 합 중 가장 큰 값을 구하는 프로그램을 작성하세요.

입력

첫 번째 줄에 정수 N, K가 공백으로 구분되어 주어집니다.

두 번째 줄에 N개의 정수가 공백으로 구분되어 주어집니다.

제한 조건
- 2 ≤N ≤100000
- 1≤K≤N
- -100 ≤ 수열의 원소 ≤100

출력

첫 번째 줄에 연속하는 K개의 원소들의 합 중 가장 큰 값을 출력합니다.

입력 예제

예제 1

입력

5 2

-10 10 -4 4 1

출력
6

예제 설명

원소 2개로 이루어진 구간 [10, −4] 를 선택하면 합이 6으로 최대가 됩니다.

예제 2

입력

10 2

3 -2 -4 -9 0 3 7 13 8 -3

출력

21

예제 설명

원소 2개로 이루어진 구간 [13, 8] 을 선택하면 합이 21로 최대가 됩니다.

예제 3
입력

10 5

3 -2 -4 -9 0 3 7 13 8 -3

출력

31

예제 설명

원소 5개로 이루어진 구간 [0, 3, 7, 13, 8] 을 선택하면 합이 31로 최대가 됩니다.

제한
- Time Limit: 3000 ms
- Memory Limit: 176 MiB

코드
``` Java
import java.util.Scanner;
public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int k = sc.nextInt();
        int[] arr = new int[n + 1];
        int[] pSum = new int[n + 1];

        for (int i = 1; i <= n; i++) {
            arr[i] = sc.nextInt();
            pSum[i] = pSum[i - 1] + arr[i];
        }

        int answer = -1000000000;

        for (int i = 1; i + k <= n; i++) {
            answer = Math.max(answer, pSum[i + k] - pSum[i]);
        }

        System.out.println(answer);
    }
}
```
